# Daily and weekly maintenance reference

This document is a reference workflow. Installing the Skill does not create a scheduler, automation, or Obsidian maintenance job.

## Daily pass

1. Find newly completed QA material since the last successful pass.
2. Extract small candidate notes with source pointers.
3. Route each candidate to a project, topic, or pending-confirmation entry.
4. Record uncertainty and conflicts instead of smoothing them away.
5. Leave durable-fact promotion for human review or explicit new evidence.

## Weekly pass

1. Check for missed material and broken source links.
2. Review stale project status and superseded conclusions.
3. Merge genuine duplicates without losing source pointers.
4. Revisit pending confirmations and unresolved conflicts.
5. Keep a short maintenance result so the next pass knows what was completed.

## Safety rules

- Automation may propose or organize candidates; it must not silently turn them into durable personal facts.
- Never copy credentials, private configuration values, or full raw conversations into a summary.
- Limit every scan by date, project, file count, or query. Avoid whole-vault context dumps.
- Keep automation configuration outside this public Skill repository.
